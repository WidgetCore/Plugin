 # WidgetCore
افزونه رایگان و متن‌باز وردپرس برای المنتور که ویجت‌های کاربردی، سبک و در دسترس‌پذیر به پنل اضافه می‌کند. بدون صفحه تنظیمات، بدون ذخیره داده در دیتابیس و بدون هیچ درخواست خارجی.
